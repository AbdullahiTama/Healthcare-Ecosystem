# Team Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Field team → Team map showing today's check-ins, visits (live) and quiet customers.

**Architecture:** A pure model turns existing data (check-in overview, visits, customers) into pins and list rows; a thin on-demand Leaflet wrapper draws them; the page loads the three sources, subscribes to new visits, and refreshes check-ins every 5 minutes while visible. No database change.

**Tech Stack:** React 18, Leaflet 1.9 (already a dependency), vitest + jsdom.

**Spec:** `docs/superpowers/specs/2026-10-25-team-map-design.md`

## Global Constraints

- No new data access, no migration. Check-ins only via `checkinRepository.overview`; visits via `liveActivityRepository.getFieldActivities`; quiet customers via `customerRepository.list(id, { quietDays: 30 })`.
- Popups built from DOM text nodes only.
- Check-in refresh: every 5 minutes (300000 ms) while `document.visibilityState === 'visible'`, plus a Refresh button.
- Fresh = within 60 minutes (`STALE_AFTER_MINUTES`).
- Module `field-map`: label 'Team map', icon `MapIcon`, section 'field-team', path '/dashboard/field-team/map', access 'field-manager', NAV_ORDER after 'field-reports'.
- One commit per task; `git add` + commit with explicit paths; `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A rep's check-in from yesterday must not appear as a pin (it would read as "here now") → model test.
2. A visit with a facility and a GPS pin is placed at the facility, labelled as the place; one with GPS only is labelled "GPS position" → model test.
3. A realtime visit for another range (e.g. older than today while "Today" is chosen) must not be added → page test.
4. The refresh timer must stop when the page is hidden or unmounted (no logged looks from a background tab) → page test.
5. A name containing `<img src=x onerror=...>` in a popup renders as text → popup test.

### Task 1: Model

**Files:** Create `apps/carehub/src/modules/live-activity/teamMap/teamMapModel.js`; Test `.../teamMap/__tests__/teamMapModel.test.js`

**Produces:** `buildTeamMap({ checkins = [], visits = [], quietCustomers = [], now, range = 'today', staffId = '', territoryId = '', showQuiet = false }) → { pins, reps, absent, visitRows, quietRows }`
- `pins`: `{ id, kind: 'rep'|'visit'|'quiet', lat, lng, tone: 'current'|'earlier'|'out'|'visit'|'quiet', title, lines: string[] }`
- `reps`: rows with a pin today `{ staffId, name, at, tone, area }`; `absent`: names with no check-in today.
- `visitRows`: visits in range (newest first) `{ id, at, rep, place, positionLabel: 'at the place'|'GPS position'|'no position', match }`.
- `RANGES = [['today','Today'],['week','This week']]`, `rangeStart(range, now)` (local midnight; week = 6 days before midnight today).

Tests: tones (20 min current, 3 h earlier, checkout out, yesterday → absent); visit at facility vs GPS vs none; range filter; rep filter applies to reps and visits; territory filter applies to visits only; quiet pins only when `showQuiet` and with coordinates.

### Task 2: Leaflet wrapper

**Files:** Create `.../teamMap/LeafletMap.jsx`; Test `.../teamMap/__tests__/popupContent.test.js`

**Produces:** `popupContent(pin) → HTMLElement` (title in `<strong>`, each line a `<div>`, all via `textContent`); default `LeafletMap({ pins, height })` loads Leaflet on demand, draws circle markers coloured by tone, binds `popupContent`, fits bounds, shows a plain error line if Leaflet fails to load.

Tests: popup text and structure; an HTML-looking name stays text (`querySelector('img')` is null).

### Task 3: Page, nav and route

**Files:** Create `.../teamMap/TeamMapPage.jsx`; Modify `apps/carehub/src/lib/permissions.js`, `apps/carehub/src/pages/dashboard/BusinessDashboard.jsx`; Tests `.../teamMap/__tests__/TeamMapPage.test.jsx`, update `lib/__tests__/fieldNav.test.js`, `pages/dashboard/__tests__/BusinessDashboard.test.jsx`.

Tests (LeafletMap mocked to render pins as elements): loading; pins and list from all sources; "Positions as of"; Refresh calls overview again; 5-minute timer refreshes when visible, not when hidden, stops on unmount; realtime visit today is added, one outside the range is not; "Live"/"Not live" line from the subscription status; per-source error with retry while the others still show; empty state; quiet layer toggle loads customers once and shows their pins; nav shows Team map for managers, not for reps; route renders the page.
