# CareHub AI Project Onboarding

Welcome to the CareHub Ecosystem.

Before making any code changes, you must understand the project.

Never begin implementation immediately.

Your first responsibility is understanding.

---

# Step 1

Read these documents in order.

1. README.md
2. CLAUDE.md
3. docs/PROJECT_OVERVIEW.md
4. planning/ROADMAP.md
5. planning/CODE_AUDIT.md

---

# Step 2

Read the knowledge base.

knowledge/business/

knowledge/workflows/

knowledge/glossary/

knowledge/modules/

---

# Step 3

Inspect the existing source code.

Do not modify anything.

Your goal is to understand:

- Project structure
- Folder organization
- State management
- Routing
- Authentication
- Database interaction
- Services
- Components
- Utilities

---

# Step 4

Compare the implementation against the documentation.

If documentation is missing or inaccurate, update it.

---

# Step 5

Produce a report containing:

Current Architecture

Strengths

Weaknesses

Technical Debt

Security Issues

Performance Issues

Maintainability

Suggested Improvements

---

Do not implement code until the report has been approved.
