# Development Session Workflow

Every development session follows this workflow.

---

## Phase 1

Understand

Read:

Roadmap

Architecture

Knowledge Base

Current Feature

Open Issues

---

## Phase 2

Inspect

Read the existing implementation.

Do not modify code.

Explain how it currently works.

---

## Phase 3

Plan

Produce an implementation plan.

Identify:

Files

Components

Hooks

Services

Database

Permissions

Testing

Documentation

---

## Phase 4

Wait

Wait for approval.

---

## Phase 5

Implement

Write code.

---

## Phase 6

Review

Review your own implementation.

Identify improvements.

---

## Phase 7

Testing

Generate tests.

Check edge cases.

---

## Phase 8

Documentation

Update documentation.

---

## Phase 9

Commit

Only after all previous phases are complete.
